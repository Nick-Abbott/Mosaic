# Mosaic 0.5.0 release notes

Mosaic 0.5.0 adds opportunistic MultiTile coalescing. Independently discovered,
uncached keys for the same MultiTile can combine before scheduled execution
begins, without caller coordination or an intentional batching delay. Exact
batch boundaries depend on scheduling.

See the [MultiTile guide](../../mosaic-core/README.md#-multitile) for batching
strategies and the [performance results](../../performance/README.md) for the
newly published measurements.
